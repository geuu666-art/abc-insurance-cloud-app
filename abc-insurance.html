ABC Insurance Digital Claims and Document Routing Service

A cloud-based demonstration service for ABC Insurance SDN BHD, supporting insurance claim processing, signed policy digitisation, physical mail routing, procurement records, stock tracking, and multi-branch access.

Overview Services Workflow Cloud Deployment Hadoop Analytics

Project Overview

ABC Insurance SDN BHD is treated as a large-scale insurance company with logistics-related operations. The purpose of this cloud service is to demonstrate how the organisation can begin migrating from hardcopy-based legacy processes to a digital, cloud-hosted workflow.

Business Context

The company operates across Kuala Lumpur, Terengganu, Johor, Penang, Sabah, and Sarawak, with vehicle and medical insurance services.

Cloud Migration Goal

The system supports digital transformation by reducing manual document handling and improving access to operational information.

Hybrid Cloud Direction

SaaS can support standard HR and procurement, PaaS can support custom claim workflows, and managed analytics can support decision-making.

Supported Digital Operations

This demonstration page represents the initial cloud service interface for the organisation's insurance and document-logistics workflows.

Claim Evidence Upload

Supports future upload of medical bills, police reports, vehicle damage photos, and other claim-related supporting documents.

Signed Policy Digitisation

Allows signed policy documents to be scanned, stored, tagged, and linked to the correct customer or claim record.

Document Routing

Helps route physical mail, scanned evidence, and claim documents to the correct branch, department, or claims officer.

Procurement and Stock Tracking

Supports the future tracking of procurement requests, courier receipts, stock movements, and internal operational resources.

Proposed Workflow

The following workflow shows how ABC Insurance can gradually move from physical documents to a cloud-supported digital process.

1

Document Collection

Branches receive claim forms, medical bills, police reports, signed policies, and courier receipts.

2

Digitisation and Metadata Tagging

Documents are scanned and tagged with claim ID, branch, date, document type, and handling status.

3

Cloud Storage and Routing

Files are securely stored and routed to the correct claims, procurement, HR, or logistics team.

4

Analytics and Decision-Making

Historical data can be analysed to identify claim delays, routing bottlenecks, and branch workload trends.

Cloud Deployment Status

This website has been deployed as a practical cloud implementation using Azure Static Web Apps.

Status: Running Successfully on Azure Static Web Apps The application is publicly accessible through an HTTPS endpoint and demonstrates broad network access for multi-branch cloud service delivery.

Potential Scaling Option

In the future, the static front end can be extended with Azure Functions as a serverless backend API and Azure Storage for uploaded claim evidence. This allows the front end, backend logic, and storage layer to scale separately when claim submissions or document-routing requests increase.

Conceptual Hadoop / Spark Analytics Layer

A Hadoop or Spark-compatible analytical layer can support long-term data analysis when ABC Insurance needs to process large volumes of structured and unstructured operational data.

Data Sources

Claim forms, medical bills, police reports, vehicle photos, signed policies, procurement logs, stock records, and branch workload data.

Processing Layer

Hadoop, Spark, Hive, or Spark SQL can process large historical datasets for batch analytics and cross-branch reporting.

Management Output

Dashboards can show claim turnaround time, document routing delays, procurement trends, and branch workload differences.

Note

This website is a demonstration for coursework purposes. It does not process real customer data, and a live Hadoop cluster has not been provisioned at this stage.
